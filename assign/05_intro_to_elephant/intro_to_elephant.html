We can also epoch the data using a time interval around each stimulus.

t_start = -0.1 * pq.s
t_stop = 0.5 * pq.s

For this, we create a Block object to store the whole recording. Then we iterate the stimuli and create a Segment for each stimulus. For each segment, we iterate the units and add a SpikeTrain for each unit. In each trial, we subtract the stimulus onset time from the spike times so they represent the spiking relatve to the stimulus

block = Block()
unit_ids = spikes["unit_id"].unique()
for i, stimulus in stimuli.iterrows():
    seg = Segment(name=f"trial-{i}")
    stimulus_onset = stimulus["start_time"]*pq.s
    win_start = stimulus_onset + t_start
    win_stop = stimulus_onset + t_stop
    segment_spikes = spikes[(win_start<=spikes["spike_time"]) & (spikes["spike_time"]<=win_stop)]
    for uid in unit_ids:
        unit_spike_times = segment_spikes[segment_spikes["unit_id"]==uid]["spike_time"]
        unit_spike_times = unit_spike_times.to_numpy() * pq.s
        unit_spike_times -= stimulus_onset
        spike_train = SpikeTrain(unit_spike_times, t_stop=t_stop, t_start=t_start, name=uid)
        seg.spiketrains.append(spike_train)
    block.segments.append(seg)
print(f"The block contains {len(block.segments)} trials")
The block contains 75 trials

With this data format, we can easliy compute a peri-stimulus time-histogram for a given unit

spike_trains = [seg.spiketrains[2] for seg in block.segments]
hist = time_histogram(spike_trains, bin_size=10*pq.ms)

The time_histogram returns an AnalogSignal which is neo’s way of representing continuous data. The start and stop of the histogram depends on the t_start and t_stop of the SpikeTrain objects and the sampling rate on the bin size. The AnalogSignal can be plotted directy with matplotlib.

plt.plot(hist.times, hist)
plt.title(f"PSTH from {hist.t_start} to {hist.t_stop} sampled at {hist.sampling_rate}")
plt.xlabel("Time [s]")
plt.ylabel("Spike Count")
Text(0, 0.5, 'Spike Count')

Or we can use a function from viziphant

plot_time_histogram(hist)
